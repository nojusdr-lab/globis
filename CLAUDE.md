# GLOBIS

GLOBIS yra Lietuvos gyvūnų globos ir įvaikinimo programėlė. Pagrindinė kalba lietuvių, technologijos Expo, React Native ir JavaScript. Discovery Engine yra atskiras Node.js ir SQLite modulis.

- Vadovaukis [AGENTS.md](AGENTS.md), [darbo perdavimu](docs/handoff/CLAUDE_CODE_HANDOFF.md) ir savininko naujausiais sprendimais. Prieš darbą patikrink gyvą GitHub būseną. Datuoti projekto dokumentai yra kontekstas.
- Pirmas prioritetas yra patikrintas duomenų surinkimas. Pradėk nuo [#24](https://github.com/nojusdr-lab/globis/issues/24), tada [#23](https://github.com/nojusdr-lab/globis/issues/23), atsižvelgdamas į jų gyvą būseną. Naudok `/globis-next` vienai įgyvendinimo iteracijai.
- Realiems šaltiniams reikia dokumentuotų prieigos ir turinio naudojimo teisių. Nuotraukų teisės fiksuojamos atskirai. Sintetiniai duomenys lieka testuose. Trūkstamos savybės lieka nežinomos. Dingęs įrašas neįrodo įvaikinimo. Nepilnas atnaujinimas negali perrašyti paskutinės patikimos kopijos.
- GLOBIS žalia yra `#245B46`. Naudok originalų logotipą, šviesų vėsų foną ir navigaciją „Globoti / Prieglaudos / Išsaugoti“. Šilta paletė yra atskiras dizaino eksperimentas. UX darbams vadovaukis `AGENTS.md` nurodytomis repo gairėmis.
- Darbui naudok atskirą šaką ir mažą peržiūrimą PR. `main` keičiamas per savininko peržiūrą. Publikavimas, išorinės išlaidos, architektūros ar prieigos pakeitimai ir susisiekimas su organizacijomis reikalauja savininko sprendimo.
- Rezultate pateik PR nuorodą, commit SHA, faktiškai atliktus testus, CI būseną ir kliūtis. Darbo vykdymą, susiejimą ir publikavimą patvirtink iš šaltinio.
