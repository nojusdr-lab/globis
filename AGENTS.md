# GLOBIS

## Mobile UI and UX

- Read the UI scope in [Issue #2](https://github.com/nojusdr-lab/globis/issues/2) and use the project owner's latest GLOBIS Project Master Context for brand decisions. Use `#245B46`, a white or cool light background, and the original GLOBIS logo asset. Keep `Globoti / Prieglaudos / Išsaugoti` and Lithuanian labels. If the logo file is unavailable, leave space for it.
- Use [Mobile App UI/UX Design](.agents/skills/mobile-app-ui-design/SKILL.md) for screen hierarchy, thumb reach, spacing and interaction states. Treat its browser examples as visual references.
- Use [UI/UX Pro Max](.agents/skills/ui-ux-pro-max/SKILL.md) for targeted accessibility and React Native audits. Treat generated palettes and design tokens as suggestions. Preserve the project's brand and existing theme.
- Use [Expo Native UI](.agents/skills/expo-native-ui/SKILL.md) for platform behavior and [Expo UI](.agents/skills/expo-ui/SKILL.md) when evaluating native controls. Adapt guidance to the installed Expo SDK, existing React Native/JavaScript structure and web support. Evaluate dependencies and navigation changes separately from design guidance.
- Verify touch targets, safe areas, screen-reader labels, reduced motion and relevant loading, empty and error states. Display sourced animal facts, statuses and contacts only.
